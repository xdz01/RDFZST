# RDFZ食堂大众点评网站

这是一个为中国人民大学附属中学（人大附中）制作的食堂菜品点评网站。

## 功能特点

- 用户注册和登录
- 查看早餐、午餐、晚餐菜品
- 为食堂菜品进行评分和点评
- 查看其他同学的点评
- 提交反馈意见

## 技术栈

- 前端：HTML, CSS
- 后端：Python, Flask
- 数据库：SQLite（未来可扩展）

## 安装说明

1. 克隆代码库
```
git clone https://github.com/yourusername/rdfz-cafeteria-review.git
cd rdfz-cafeteria-review
```

2. 安装依赖
```
pip install -r requirements.txt
```

3. 运行应用
```
python app.py
```

4. 在浏览器中访问
```
http://localhost:5000
```

## 项目结构

- `app.py`: 主应用程序
- `templates/`: HTML模板文件
- `static/`: 静态文件（CSS, JS, 图片）
