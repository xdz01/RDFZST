# RDFZ食堂大众点评

这是中国人民大学附属中学制作的食堂菜品点评网站。

## 功能

- 用户管理系统
- 查看早餐、午餐、晚餐、小卖部的菜品
- 为食堂菜品进行评分和点评
- 查看其他同学的点评
- 对菜品和鉴赏家进行排行
- 提交反馈意见

## 技术栈

- 前端：HTML, CSS
- 后端：Python, Flask
- 数据库：SQLite（可扩展）

## 安装说明

1. 克隆代码库

```
git clone https://github.com/xdz01/RDFZST.git
cd RDFZST
```

1. 安装依赖

```
pip install -r requirements.txt
```

1. 运行应用

```
python app.py
```

1. 在浏览器中访问

```
http://localhost:5000
```

## 项目结构

- `app.py`: 主应用程序
- `templates/`: HTML模板文件
- `static/`: 静态文件（CSS, JS, 图片）
